# Agent Notes

Store decisions in `<status>/<category>/YYYY-MM-DD-topic.md`. Status is proposed,
implemented, rejected, or archived. Notes start with a title and matching Status,
then describe the problem, decision, alternatives, verification and consequences.
Use evidence and observable behavior; keep chat transcripts and hidden reasoning
out of notes. Search active notes before creating another record. Archived notes
are frozen and provide historical context only.
